# 🌟 Stellar Trading Bot

**Автоматический торговый бот для блокчейна Stellar (RUV/XLM)** с техническим анализом, веб-доской и управлением рисками.

---

## 🧰 Функционал
- **Индикаторы**: MA, RSI, MACD
- **Управление рисками**: Стоп-лосс, тейк-профит
- **Логирование**: В файл и консоль
- **Веб-доска**: Отслеживание сделок и ордеров в реальном времени
- **Email-уведомления**: Прибыль/убыток, ошибки
- **Поддержка тестнета и мейнета**

---

## 📦 Требования
- Node.js v18.x или выше
- npm
